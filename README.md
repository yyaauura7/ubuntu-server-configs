# Лаборатория DevOps

## Глава 1 — Умный вышибала (Nginx + UFW)
* **Построенная архитектура:** Реализована эшелонированная защита (Defense in Depth). Сервер защищен UFW (файрволом), который блокирует все входящие соединения и пропускает трафик только по портам 22 (SSH) и 80 (HTTP). В роли веб-сервера выступает Nginx, который использует концепцию Server Blocks для приема гостей по доменному имени и маршрутизации их в нужную директорию с кастомным HTML-кодом.
* **Освоенные технологии:** UFW, Nginx, curl, w3m. Разрешены проблемы с кодировкой (utf-8) и маршрутизацией IPv4/IPv6.
* **Новые команды в арсенале:**
  * Управление защитой: `ufw status verbose`, `ufw allow 'Nginx HTTP'`, `ufw enable`, `ufw app list`.
  * Траблшутинг сетей: `curl -4 ifconfig.me`, `curl -I http://localhost`.
  * Работа с Nginx: `ln -s`, `nginx -t`, `systemctl reload nginx`.
